## Changes

- Set tier and activity targets under `modes.cost` and `modes.quality`. Activity targets can inherit fields from their mode's tier target. Compatibility, context and switching checks still apply.
- Expand the Policy view's activity routes with `r` to inspect route sources and unavailable preferences. Before the context has been measured, the panel identifies eligibility as unverified.
- Honor upgrade and downgrade vote thresholds greater than three. Reject malformed classifier tier distributions instead of treating invalid probability mass as routing evidence.
