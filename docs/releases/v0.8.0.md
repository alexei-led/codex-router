The Usage view now separates savings from extra cost and keeps the net comparison in its headline. Cheaper and costlier replies remain visible even when their costs cancel out. Paying more for a suitable model is reported as extra cost without changing routing decisions.

Sub-cent estimates use four decimal places, and positive amounts below $0.0001 no longer round to zero. Equal totals show `same estimated cost`. A priced zero-cost baseline shows the extra amount without an undefined percentage. Incomplete pricing still shows coverage instead of dollar totals.

Accounting uses the backend's served model when priced, including explicit prices for model variants. The comparison uses the observed tokens at each model's prices. It does not estimate task quality, alternative reasoning usage or alternative cache behavior.

The guide and sample panel images reflect the new figures. Live checks with Codex 0.163.0 in agterm verified both savings and extra cost, and confirmed that Codex's bottom status line follows the routed model and effort.

After upgrading the binary in place, restart the home's services and any running `codex-router` launchers to use the new accounting. Existing running processes keep the old code. Totals cover replies observed by the new process; historical replies are not recalculated. If the binary moves, rerun setup.
