## Summary

Fix a phase-confidence gap in mode-gated operational routing introduced in v0.13.0.

## Changes

- Newly accepted ops reasoning/code projections must pass their actual phase-confidence and cache-cost bar before the mode gate, even when the activity label is unchanged. A high complexity score no longer substitutes for weaker phase evidence.
- Refused projections retain the incumbent pair and semantic provenance. Stronger phase evidence can still pass the normal mode vote and hold rules.
- Existing accepted floor intent, valid context refits and explicit operator mode changes keep their established gates. Model assignments, prices, pins, cancellation and eligibility behavior are unchanged.

## Upgrade

Restart routed sessions with the updated binary and update the Codex plugin to 0.13.1. No configuration migration is required.
