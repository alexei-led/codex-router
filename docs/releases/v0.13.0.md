## Summary

Operational goals now use phase-appropriate routing preferences without losing goal continuity. Tariff changes no longer reverse declared model capability order.

## Changes

- Accepted ops reasoning targets the same-tier debug preference; production targets code. Bounded verify/execute retains ops. Existing confidence, cache, dwell, passed-check, pin, cancellation and eligibility gates still control switching.
- Ops report or uncertain phase evidence preserves an eligible continuation activity and uses the generic baseline on a fresh task. Missing phase, including Ollama's phase-free answers, no longer authorizes a fresh ops discount. No local keyword tiers were added.
- Model upgrade/downgrade gates use declared generic tier order and same-model effort, not input or output prices. Activity-only models remain unordered. Cost mode still uses input prices for its economic model lever.
- Decision and debug reply diagnostics distinguish requested, selected and response-body model identity, with configured-price estimate coverage. They do not claim served effort, backend attestation, delegated-task coverage or actual bills.
- Explicit debug/code cells remain user-owned. A weaker or unordered inherited generic floor retains ops; explicit unordered continuation floors must still pass lateral and mode gates.
- Existing OpenAI model assignment tables are unchanged. Standard list prices are unchanged, checked against OpenAI on 2026-11-15; long context and cache-write charges remain outside the estimate.

## Upgrade

1. Close routed Codex sessions, replace the binary and restart. Follow the [update guide](https://github.com/alexei-led/codex-router/blob/v0.13.0/docs/user-guide.md#update-or-uninstall) for set-up homes.
2. Update the Codex plugin to 0.13.0. Existing explicit cells remain user-owned. Review custom ladders that relied on price to establish capability order; declare the intended generic model-tier order instead.
