Setup now preserves user-owned `codex-router.env` paths. It refuses to overwrite an unmarked file, symlink or directory, and undo leaves those paths alone. Files created by earlier setup versions still work.

The README now explains the problem, hosted and local classifier setup, privacy and known limits. The guide covers updates and uninstalling. Benchmark details have moved to a separate evaluation page. Terminal illustrations now label their sample data.

The unused `downgradeHorizonTurns` setting is gone from defaults and presets. Existing configs still accept it, with no effect.

Before updating a home installed with setup, close its Codex sessions, replace the binary and rerun setup with the original options and environment. Close those sessions before undoing setup too: running threads keep the old provider, and another local process could take its freed port and receive ChatGPT credentials.
