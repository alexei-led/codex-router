## Summary

The panel, the hook line and the CLI now read the same way. A tier is a meter, a reason starts with a glyph, and cost is one signed figure against **no routing**. The routing itself does not change: the same tier and route are chosen for the same input.

## Changes

- **Tier meter.** `▂` micro, `▂▄` low, `▂▄▆` medium, `▂▄▆█` high, on the panel, the hook line and `ctl`. The tier strip uses one bar per turn. Pin buttons show the meter and the name, and keep all four on a narrow panel. Tier names stay as typed input (`ctl pin --tier high`).
- **One reason text per reason**, led by a glyph: `↑` stronger, `↓` cheaper, `=` stays, `…` waits, `!` fault, `⏵` pin, `○` off. The hook and the panel share it.
- **Cost against no routing.** The Session and Usage figures are one signed difference: `−$0.84 (−31%) vs no routing · ≈ list price`. Minus is cheaper. No routing is the model Codex asked for on each reply. Amounts have two decimals, and a nonzero amount under a cent reads `<$0.01`. Usage adds `per reply: cheaper … · dearer …` and says the figures cover the main thread. "Ledger", "native basis" and "switch gates" are gone.
- **Hook line.** `↳ Hook · ▂▄▆█ debug → gpt-6.1-sol · high  ↑ repeated failure, edit between`. The `router:` prefix and the tier word are gone. A turn with several steps now keeps the reason that changed the route, not `= same turn`.
- **CLI.** `ctl status` prints `state` (`● on`, `‖ paused`, `◐ manual`, `↑ escalated`) in place of `mode` and `attention`. `sessions` has a `STATE` column and, on a terminal only, a header row. `sessions --json` is unchanged. `ctl` confirmations are shorter.
- **Panel.** `Look` is `Notes`, `Ledger` is `Counts`, and the switching line reads `up after 2 votes at score ≥ 0.65`. The Usage tab no longer ends a pinned switch with a stray `·`. Token counts use an upper-case `K` everywhere.
- **Prices.** The built-in prices are unchanged and match the OpenAI pricing page (Standard, up to 272K input tokens), checked 2026-11-04. The source and date are in `internal/config/default.go` and `docs/configuration.md`. Long context, Fast, batch and flex, and regional pricing are not modeled.

## Upgrade

1. Close routed Codex sessions, replace the binary and start Codex again. A set-up home needs [setup rerun](https://github.com/alexei-led/codex-router/blob/v0.12.0/docs/user-guide.md#update-or-uninstall) as for any release.
2. Update the Codex plugin to 0.12.0 for the new skill text. The hook line comes from the binary.
3. Scripts that read `ctl status` text must read `state` where they read `mode` or `attention`. Scripts that read the `sessions` table get a `STATE` column. Use `sessions --json` for stable fields.
