## Summary

The plugin now installs and updates the binary it needs. `codex-router self-update` replaces the installed executable with a verified release build, and the plugin's session-start hook runs it when the plugin and the binary disagree.

## Changes

- New `codex-router self-update` with `--check` and `--to vX.Y.Z`. It resolves the release, downloads the asset for this platform, checks it against the release's `checksums.txt`, runs the downloaded file's `version` and renames it into place only when every check passes. A failed check leaves the installed binary untouched.
- The plugin's SessionStart hook compares its own version with `codex-router version` and updates the binary to the plugin's release. `codex plugin add` and a marketplace upgrade now bring the binary with them.
- `CODEX_ROUTER_NO_SELF_UPDATE=1` keeps the hook from replacing the binary.

## Upgrade

1. Install this release the usual way once, with the [install](https://github.com/alexei-led/codex-router/blob/v0.12.0/docs/user-guide.md#install) steps: `self-update` cannot exist in the binary you are replacing.
2. Update the plugin per home. From then on the first session after a plugin update updates the binary by itself; that session still runs the previous binary.
3. Set `CODEX_ROUTER_NO_SELF_UPDATE=1` if a hook must not replace the executable on your machine.
